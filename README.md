# Artificial Intelligence Tasks "CodeAlpha"

## Tasks

### Task N°1: "Language Translation"
- Interactive command-line interface with continuous translation loop (`exit` to quit).
- Supports source and target language codes (e.g., `english`, `french`, `arabic`...).
- Clean error handling for invalid inputs or network issues.
- Used `MyMemoryTranslator`.

### Task N°2: "FAQ Chatbot"
- Lowercasing and punctuation removal using Python's `string` module.
- Using `TF-IDF Vectorization` to focus on meaningful keywords.
- Similarity matching using `Cosine Similarity` with a confidence threshold (`0.2`) to reject off-topic questions gracefully.
- Used `string`.
- Used `scikit-learn`.
